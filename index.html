구성원으로서 맡은 자리에서 성실하게 책임을 다해 왔습니다. 더 배우고 직접 사용해 보고 싶은 열정과 호기심을 바탕으로, 새로운 환경과 기술에도 꾸준히 적응하며 공부합니다.

반복 테스트 및 반복되는 수정 과정에서 더 나은 결과를 만들어 가는 방식을 중요하게 생각합니다. 필요할 때는 먼저 문제를 파고들고, 평소에는 팀이 안정적으로 움직일 수 있도록 받치는 사람입니다.

결함을 적극적으로 발견하되 단순한 건수보다, 고위험 이슈를 먼저 확인해 릴리즈 리스크를 줄이는 것에 집중합니다. 보안 감각과 꾸준한 체력 관리 역시 안정적으로 업무를 수행하기 위한 기본 역량이라고 생각합니다.

제 비전은 멈추지 않고 배우며 성장하는 엔지니어입니다. 사람과 업무의 흐름을 함께 이해하며, 팀에 신뢰를 더하는 구성원이 되고자 합니다.

Beyond Testing

테스트를 수행하는 데서 멈추지 않고, 품질이 만들어지는 과정 전체를 이해하고 개선하는 일에 관심이 많습니다. 대기업 커머스 프로젝트를 경험하며 요구사항, 개발, 테스트, 릴리즈로 이어지는 SDLC와 개발 팀의 업무 흐름을 가까이에서 익혔습니다.

특히 주문과 같이 서비스의 핵심이 되는 커머스 도메인을 경험하며, 기능의 정상 동작뿐 아니라 장애 발생 시 영향 범위와 사용자 경험까지 함께 바라보려 합니다. 개발자가 만든 결과물을 검증하는 것을 넘어, 어떤 지점이 가장 큰 비즈니스 리스크가 될 수 있는지 판단하는 테스트를 지향합니다.

테스트 관점과 개발 관점을 함께 가지고 문제를 바라봅니다. 반복적으로 검증해야 하는 영역은 자동화하되, 단순히 자동화 범위를 넓히기보다 무엇을 자동화해야 실제 가치가 있는지를 고민합니다. 반대로 사람의 판단이 필요한 영역은 더 선명하게 구분해 품질 활동의 효율을 높이고자 합니다.

C, Java, 컴퓨터과학, 소프트웨어공학, SQL, 자바 등 웹 개발을 학습했고, Playwright 기반 자동화 구축에도 AI 도구를 활용해 왔습니다. AI를 단순한 코딩 보조가 아니라 학습·분석·자동화 구축의 속도를 높이는 도구로 활용하며, 배운 기술을 실제 검증 방식의 개선으로 연결하려 합니다.

제가 지향하는 TAE는 혼자 자동화 코드를 만드는 사람을 넘어, 개발과 테스트 사이를 연결하고 팀의 테스트 방식을 더 나은 방향으로 움직이는 사람입니다. 문제를 찾는 데서 끝나지 않고, 품질의 흐름 자체를 개선하는 엔지니어로 성장하겠습니다.
